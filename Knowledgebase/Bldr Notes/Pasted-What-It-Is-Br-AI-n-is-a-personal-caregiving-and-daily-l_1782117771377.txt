What It Is
Br[AI]n is a personal caregiving and daily-life management app built for a specific person — referred to throughout the codebase as "Pops" — who is a veteran living with a caregiver named Ray. The app is a React/TypeScript PWA (Progressive Web App) with a Miami Vice dark aesthetic, built on Vite + TailwindCSS, and has a companion Android build via Capacitor.
The Core Problem It Solves
Pops is on Haloperidol (Haldol) — a long-acting antipsychotic injection given on a 14-day cycle. The app is built around the reality that his cognitive capacity, energy, and effort level fluctuate predictably across that cycle:

The UI adapts to this — "Zombie Mode" dims the interface and reduces expectations. Tasks are scheduled, notified, and tracked against this biological rhythm.
Key Modules
Daily Routine Engine (useTasks, constants.ts) — A structured daily task list organized into time blocks (Early AM 04:00–08:00, Morning, Afternoon, Evening). Tasks include medication reminders, stretching, cleaning, sprinkler checks, laundry — each with specific notification times and optional sound effects (bell for meds, horn for critical tasks).
Haldol Cycle Tracker (haldolService.ts) — Anchored to a real injection date (Jan 15, 2026), it calculates the current cycle day and phase in real time, driving the app's effort/mood state.
Caregiver Panel (CaregiverPanel.tsx) — A protected admin section for Ray showing a compliance rate (% of tasks completed), with controls to add tasks or reset the daily state.
Brain Puzzle (BrainPuzzleModal.tsx) — A Simon-style color sequence memory game used as a morning cognitive warmup — one of the scheduled daily tasks.
Br[AI]n Shopper (src/components/shopper/) — A full household grocery/meal planning sub-system with its own profile (shopper-profile.json). Includes a weekly meal planner, grocery list, budget tracker ($150/week, $600/month), cart approval workflow, and household intake form. Planned for integration into the main app per INTEGRATE.md.
VA Edition (pops-tracker---va-edition/) — A separate, stripped-down fork of the app described as a "high-contrast, accessible daily routine tracker designed for veterans" with a USS Nimitz Navy theme and offline capability. This appears to be a cleaner/deployable version of the core tracker.
Sound & Notification System (soundService.ts, useAlarmSystem) — Plays audio cues at scheduled task times and integrates with ntfy.sh (topic: pops_tracker) for push notifications.

  What was actually broken: The server routes were fine. In the admin Schedule Editor, only the
  complete/uncomplete mutations refreshed the React Query cache — create, update, and delete never did,
  and window-focus refetching is off globally. So every edit saved to the server but the screen never
  updated, and it was worse than just "stale": when a drag ended, the drag-and-drop board re-derived its
  rows from that stale cache, so dropped cards and inline time/title edits visibly snapped back to their
  old values. Editing looked completely dead even though the database was changing underneath.

  Fixes applied:

  - admin-view.tsx — the create, update, and delete mutations now invalidate the schedule query the same
    way complete/uncomplete already did. New tasks appear, modal edits stick, deletes disappear, drags
    persist.
  - schedule-dnd.tsx — the board no longer re-syncs from the still-stale cache at the moment a drag ends
    (that was the snap-back); it waits for the refetch, and explicitly resets itself when a drag lands
    nowhere or produces no changes. Also wired up the missing onDragCancel: previously, pressing Escape
    mid-drag left the board permanently wedged — the drag overlay stuck and all future server updates
    ignored.
  - Stale quarter labels — the editor still showed the old clock-even quarters ("Q1 — Morning
    (0600-1200)" etc.). Updated the column headers and the modal's quarter dropdown to Ray's boundaries
    (Q1 6–10, Q2 10–14, Q3 14–18, Q4 18–6), and removed a dead duplicate of the old labels. In
    calendar.ts, "push to calendar" put Q3 tasks at 6 PM — which is already Q4 under the current
    boundaries — so Q3 now lands at 4 PM.

  There's no test framework in this repo, so verification was pnpm run typecheck (clean) plus tracing the
  data flow. Worth a 30-second manual pass on /admin → Schedule: add a task, drag one across quarters,
  click a time label to edit it inline — all three should now update on screen immediately. Say the word
  if you want this committed.

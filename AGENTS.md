## Product identity

**Brain Guardian OS** — a public, multi-tenant AI caregiving platform.

The earlier working name **br(AI)n App** came from the Google AI Studio prototype/build flow and may still appear in legacy folders, comments, or imported docs. **Brain Guardian OS** is the current product name. Do not use br(AI)n App as the product name in new code, schema, prompts, or harness files.

Roles: **admin** (caregiver who operates the system), **caregiver** (secondary care team), **patient** (care recipient). Never hardcode personal names into schema defaults, route handlers, seeds, prompts, or platform docs.

## System map

| Layer | What it is | Part of this repo? |
|---|---|---|
| Guardian Core | Multi-tenant caregiving API + frontend | Yes |
| Guardian Hermes Adapter | In-app dispatch + `care_events` ledger + learning foundation | Yes (in-app) |
| OpenClaw / ClawX | Optional local runtime/integration layer | No |
| LM Studio | Local model provider (Guardian and/or OpenClaw) | No |

Edits to this repo do not touch OpenClaw, ClawX, or LM Studio unless explicitly scoped.

`care_events` is an **append-only evidence ledger** (audit trail). It is not a blockchain, not a crypto ledger, and not a reversible log. Every row must include `tenant_id` derived from the active session — never from a client-supplied field, never `"local"` as a fallback.

## Non-negotiable rules for all agents

1. **One active writer at a time.** Before editing: `git pull --rebase`. After: commit and push. Never edit on two machines simultaneously.
2. **Proof block before any session:**
   ```
   pwd
   git rev-parse --show-toplevel
   git remote -v
   git status --short
   ```
   If any of these look wrong, stop and report. Do not edit.
3. **No broad rewrites.** Propose changes, wait for approval. Targeted fixes only unless explicitly told otherwise.
4. **Open the repo root** — not a subfolder (`artifacts/brain-app`, `artifacts/api-server`, etc.).
5. **care_events rows must include `tenant_id`** derived from the session, never client-supplied, never `"local"` as a fallback.
6. **Doctor files and clinical summaries must source from verified `care_events`** — not loose AI-generated text passed off as clinical records.
7. **CORS is exact-match.** No `startsWith`, no wildcards.
8. **Generated files are never hand-edited.** `lib/api-client-react/src/generated/` and `lib/api-zod/src/generated/` are regenerated by codegen only.
9. **`import { z } from "zod/v4"`** — not `"zod"`.
10. **Canonical remote:** `https://github.com/shadowsys-memphis/Guardian.git` — HTTPS only. Do not use `LEDGERGHOST90` for this repo.

## Branch discipline

- `master` — stable, always deployable
- Feature/pass branches (e.g. `mobile-admin-pwa-pass`) — one machine owns the branch at a time
- Never force-push `master`
- Always fast-forward merge or rebase — no merge commits into master without approval
